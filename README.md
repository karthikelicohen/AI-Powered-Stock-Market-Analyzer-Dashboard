# AI-Powered-Stock-Market-Analyzer-Dashboard
Developed an AI-powered stock market analysis dashboard using Streamlit and Python. Integrated real-time stock data visualization, technical indicators (RSI, Moving Averages), breakout detection, portfolio analysis, heatmaps, and AI-based news sentiment analysis using NLP techniques.
# AI Stock Analyzer Dashboard

## Features
- Live stock analysis
- Candlestick charts
- RSI indicator
- Moving averages
- Breakout scanner
- Portfolio analysis
- Heatmap visualization
- AI news sentiment analysis

## Technologies
- Python
- Streamlit
- Plotly
- yFinance
- Pandas
- NumPy
- TextBlob

## Run Project

streamlit run app.py
